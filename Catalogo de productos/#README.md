## Descripción de la página web

Esta página web es un catálogo de productos tecnológicos realizado utilizando HTML y CSS. En ella se muestran diferentes productos con sus imágenes, nombres, precios y botones de compra.

## Descripción de la tarjeta diseñada

La tarjeta contiene cuatro productos tecnológicos:

1. Computadora - RD$ 34,000
2. Reloj inteligente - RD$ 16,000
3. Teléfono - RD$ 15,000
4. Auriculares - RD$ 850

El diseño utiliza colores, bordes redondeados, imágenes y botones. Los productos están organizados mediante CSS.

## Tecnologías utilizadas

- HTML
- CSS
